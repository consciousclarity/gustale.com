# CULINARY-REFERENCES — the project's permanent reference library

**Owner:** Alejandro
**Created:** 2026-11-11
**Supplied by:** Alejandro, 11 November 2026
**Purpose:** a permanent, durable list of culinary reference sites to be used
for future feature planning and research (recipes, atlases, taxonomies,
heritage, editorial references).

**Status of the entries:** these links were **supplied by the owner on
11 November 2026**. They are **NOT verified**. They have not been reviewed,
audited, fetched, or assessed for content quality, licensing, scrapability,
or data availability. Nothing in this file asserts that any of these sites
is reachable, current, trustworthy, or usable as a source. Treat each as a
*candidate* reference to investigate when the work calls for it.

**Count:** 55 links across 5 groups. Distinct subpages of the same site are
kept as separate entries (e.g. `allgastronomy.com` and
`allgastronomy.com/about`) because they are different resources.

---

## Project priority (recorded 11 November 2026)

**Broaden Gustale's functionality with simple, useful implementations.
Avoid overengineering.**

Operating consequences of this priority:

- Ship working, simple features first. Do not build infrastructure that
  only pays off on a hypothetical future scale.
- **Detailed sourcing, repetitive research, and cleanup are later work, and
  may be delegated to subagents running in parallel.**
- **Exhaustive sourcing completion must NOT block feature development.**
  A feature does not wait for the evidence base to be complete.

This note is a standing project priority, not a one-off task instruction.
