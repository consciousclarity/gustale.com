# scripts/

One-off utility scripts. Run via `python3 scripts/<name>.py` after `cd`-ing into the repo root.

## upload-dish-images.py

Bulk-uploads AI-generated PNG images to Gustale's media library and attaches them as cover images to the corresponding dishes.

### What it does

1. Reads PNG files from `/tmp/gustale-images-batch/<slug>.png` (60 files, ~97 MB total)
2. Authenticates to Gustale via better-auth email+password
3. For each image:
   - POST `/api/media/upload` (multipart, auth-gated) → `media_id`
   - POST `/api/dishes/<slug>/media` (JSON, auth-gated) → attaches as `role='cover'`
4. Writes a CSV + JSON manifest of results

### Modes

| Mode | What happens | Auth required |
| --- | --- | --- |
| `--dry-run` (or `GUSTALE_DRY_RUN=1`) | Lists what would be uploaded. No HTTP write. | No |
| `--limit N` | Process only the first N dishes (useful for testing) | Yes (unless also `--dry-run`) |
| `--force` (or `GUSTALE_FORCE=1`) | Re-upload even if slug already in manifest | Yes |
| Default | Real upload, all 60 dishes, resume-safe | Yes |

### Required env vars (real mode only)

```bash
export GUSTALE_API_BASE="https://api.gustale.com"   # default
export GUSTALE_EMAIL="[email protected]"
export GUSTALE_PASSWORD="your-password-here"
```

### Usage examples

```bash
# 1. Preview — list what would happen, no uploads
python3 scripts/upload-dish-images.py --dry-run

# 2. Test with 2 dishes (uploads for real)
python3 scripts/upload-dish-images.py --limit 2

# 3. Full run (resumes safely if interrupted)
python3 scripts/upload-dish-images.py

# 4. Re-upload everything (overwrites manifest)
GUSTALE_FORCE=1 python3 scripts/upload-dish-images.py
```

### Output

- `scripts/upload-manifest.csv` — per-dish results (`slug, status, media_id, role, attempted_at, error`)
- `scripts/upload-manifest.json` — same data as JSON

### Auth notes

Better-auth sets the session cookie `__Secure-gustale.session_token` on `api.gustale.com`. The script captures this cookie on first request and forwards it on every subsequent upload/attach call. Cookie is discarded at process exit.

### Rate limiting

One upload every 0.5 seconds = ~2 req/sec. Well within Gustale's rate limit. A full 60-dish run takes ~30 seconds.

### Where the images came from

Images were generated by Gemini 2.5 Flash (via `gemini-2.5-flash-image:generateContent`) using the manifest at `/tmp/gustale-images-batch/_manifest.json`. Each prompt was a per-dish photography recipe (cuisine hint + dish type + visual specifications). All images are flagged with `credit="AI-generated (Gemini 2.5 Flash)"` and `license="CC-BY-SA-4.0"` so the source is auditable.

### Important: rebuild after upload

After upload + attach, the front-end Astro SSG needs to rebuild so the new `coverImage` URLs appear on the dish pages. The rebuild is triggered by pushing an empty commit to `main` (per `.hermes/SHARED_STATE.md` "Conventions" section). **Do not auto-rebuild from this script** — let the user decide when to cut a release.
