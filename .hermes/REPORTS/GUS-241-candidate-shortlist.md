# GUS-241 — candidate shortlist for review

Every row below has a **verified English Wikipedia article** (action API, curl -4, 2026-10-27). Where the requested title is a **redirect**, the target article is given — the citation must use the target.

Techniques and courses are restricted to the live controlled vocabularies (25 techniques, 8 courses). **Difficulty** is the point: it says which dimension resists classification and therefore which vocabulary extension the dish would force.

Difficulty tags used below:

- **VESSEL** — the cooking container is part of the dish's identity
- **MULTI-COMPONENT** — more than one thing in one dish
- **COURSE-VARIABLE** — the course depends on the meal
- **DISH+DRINK** — one preparation served as both
- **DIASPORA** — the same name changed meaning across migration
- **NO-FAMILY** — no existing family fits
- **NO-TECHNIQUE** — no existing technique value fits
- **DUPLICATE** — already in the catalog
- **FIX** — already published, but a gap to fill
